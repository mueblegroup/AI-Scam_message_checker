ℹ️ About This Project

ScamShield AI is a rule-based AI web application designed to detect scam and phishing messages using intelligent keyword analysis.

The system supports both English and Bahasa Malaysia scam patterns to improve digital safety awareness among Malaysian users.

🎯 Purpose

  • Detect scam messages in real time
  • Educate users about phishing risks
  • Improve awareness of online fraud

👨‍🎓 Academic Context

This project was developed as part of an AI web development assignment to demonstrate practical implementation of rule-based intelligence systems.
